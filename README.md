# ZedoDev Open — Formação Fullstack Sênior PHP & Laravel

Plataforma educacional **100% gratuita, acessível e sem fins lucrativos** voltada para arquitetura moderna em PHP 8.4, Laravel 12, Vue 3, Inertia.js, Docker e DevOps.

## Funcionalidades
- **Apostilas em PDF Embutidas:** Leitura e download direto na plataforma.
- **Acessibilidade por Voz (pt-BR):** Narração integrada das apostilas com controle de pausa e velocidade.
- **Gerador de Currículo Técnico:** Exportação em PDF e cópia formatada para LinkedIn.
